# Pantau CCTV Palembang

Halaman tidak resmi yang merangkum stream CCTV publik kota Palembang (`stream.palembang.go.id/cam1` s.d. `cam50`) dalam satu grid.

- Nama lokasi: ubah daftar `LOKASI` di `index.html`.
- Urutan tampil: ubah daftar `URUTAN` di `index.html`.

Bukan situs resmi Pemerintah Kota Palembang.
